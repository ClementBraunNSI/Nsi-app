# 🕸️ Atelier Réseaux Sociaux : Le Graphe d'Amis

Un réseau social peut être modélisé par un **graphe** :
- Les **nœuds** (cercles) sont les utilisateurs.
- Les **arêtes** (lignes) sont les liens d'amitié.
