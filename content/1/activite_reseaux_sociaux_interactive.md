# 🕸️ Atelier Réseaux Sociaux : Le Graphe d'Amis

Un réseau social peut être modélisé par un **graphe** :
- Les **nœuds** (cercles) sont les utilisateurs.
- Les **arêtes** (lignes) sont les liens d'amitié.

## 🎯 Visualisation
Clique sur un personnage pour voir ses amis directs (voisins) et comment il est connecté aux autres.

## 🔍 Analyse
1. Qui a le plus d'amis ? (C'est le nœud avec le plus haut "degré")
2. Quel est le chemin le plus court entre **Alice** et **David** ?
3. Si **Bob** quitte le réseau, le réseau est-il coupé en deux ?
