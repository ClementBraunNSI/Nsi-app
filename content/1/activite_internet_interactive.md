# 🌐 Atelier Internet : Le Packet Tracer

Internet est un réseau de réseaux. Lorsqu'on envoie une donnée (un paquet), elle passe par plusieurs routeurs avant d'arriver à destination.

## 🎯 Simulation
Clique sur **"Lancer un PING"** pour voir comment le paquet voyage de l'ordinateur d'Alice jusqu'au serveur Web de Google (8.8.8.8).

## 🧠 Analyse
1. Pourquoi le paquet passe-t-il par le **Routeur B** et non le C ?
2. Que se passe-t-il si un routeur tombe en panne ? (C'est la résilience d'Internet !)
