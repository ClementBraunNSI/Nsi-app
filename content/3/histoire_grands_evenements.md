# 📜 Histoire de l'Informatique

L'informatique n'est pas née avec l'ordinateur. C'est la science du traitement automatique de l'information.

## 1. Les Précurseurs

*   **Antiquité** : Le boulier (abaque) pour calculer.
*   **1642 - Pascaline** (Blaise Pascal) : Première machine à calculer mécanique (addition/soustraction).
*   **1801 - Métier Jacquard** : Utilisation de **cartes perforées** pour programmer des motifs de tissage. C'est l'ancêtre du programme !
*   **1834 - Machine Analytique** (Charles Babbage & Ada Lovelace) : Concept de l'ordinateur moderne (mémoire, processeur). **Ada Lovelace** écrit le premier algorithme et est considérée comme la première programmeuse de l'histoire.

## 2. La Naissance de l'Ordinateur (XXe siècle)

*   **1936 - Alan Turing** : Concept théorique de la Machine de Turing.
*   **1945 - Architecture de Von Neumann** : Modèle théorique encore utilisé (CPU + Mémoire + Bus).
*   **1947 - Le Transistor** : Remplaçant des tubes à vide (lampes), il permet de miniaturiser les circuits.
*   **1969 - ARPANET** : Ancêtre d'Internet (4 ordinateurs reliés).

## 3. L'Ère Moderne

*   **1971 - Le Microprocesseur** (Intel 4004) : Tout un CPU sur une seule puce.
*   **Années 80** : L'informatique personnelle (Apple II, IBM PC).
*   **1991 - Le Web (WWW)** : Tim Berners-Lee invente le protocole HTTP et le HTML au CERN. Internet devient accessible au grand public.
*   **Années 2000** : Le Smartphone, les réseaux sociaux, le Big Data.
*   **Années 2010-2020** : L'Intelligence Artificielle (Deep Learning).
