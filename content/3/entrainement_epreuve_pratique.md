# Entraînement épreuve pratique

## 1. Format conseillé

- 30 à 40 minutes par sujet.
- Deux parties :
  1. lecture / compréhension de code ;
  2. fonction à compléter + tests.

## 2. Sujet type A - Récursivité

- Expliquer le résultat d'une fonction récursive.
- Compléter une fonction.
- Ajouter des tests.

## 3. Sujet type B - ABR

- Expliquer une insertion.
- Compléter `recherche_abr`.
- Tester cas normal + cas limite.

## 4. Sujet type C - Graphes

- Lire une représentation de graphe.
- Compléter un BFS ou DFS.
- Vérifier sur un exemple.

## 5. Sujet type D - SQL + Python

- Écrire deux requêtes SQL.
- Exploiter les résultats dans un script Python.

## 6. Auto-évaluation

- Mon code s'exécute-t-il ?
- Ai-je traité les cas limites ?
- Ai-je ajouté des tests ?
- Puis-je expliquer mes choix ?
