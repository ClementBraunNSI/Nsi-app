# ProjetSuivi

Suivi de projets et TP — matrice élèves × étapes.

## Démarrage

```bash
cd tools
npm install
npm run dev -w projetsuivi
```

## Fonctionnalités

- Projet configurable (défaut : Site bestiaire SNT)
- Import CSV élèves, ajout manuel
- Statuts : non commencé, en cours, rendu, validé
- Filtre « qui n'a pas rendu l'étape X »
- Commentaires par cellule
- Export CSV conseil, backup JSON
- Persistance localStorage
