# ConseilNote

Appréciations conseil de classe NSI — traitement 100 % local.

## Démarrage

```bash
cd tools
npm install
npm run dev -w conseilnote
```

## Fonctionnalités

- Import CSV (colonnes nom + moyenne)
- Modèles d'appréciations par tranche de moyenne
- Génération de brouillons, édition inline
- Export `.txt`, copie individuelle
- Persistance localStorage
